# التشريح الشعاعي — QDU

إعداد مقتدى الكناني. تضم المنصة 193 سؤالًا من الملفين المرسلين. تُعرض الأسئلة والخيارات بالإنكليزية، وتظهر الترجمة عند تفعيلها من شريط الاختبار. لكل سؤال شرح علمي باللهجة العراقية يظهر بعد الإجابة الخاطئة ومن زر «لماذا هذه الإجابة؟» وفي مراجعة النتائج.

## الأقسام

| الاختبار | أرقام الأسئلة في الملف | العدد |
| --- | --- | --- |
| مرشحات التشريح | 1–53 من المرشحات | 53 |
| أسئلة التشريح الإضافية، المحاضرة 1 | 1–33 | 33 |
| أسئلة التشريح الإضافية، المحاضرة 2 | 34–55 | 22 |
| أسئلة التشريح الإضافية، المحاضرة 3 | 56–94 | 39 |
| أسئلة التشريح الإضافية، المحاضرة 4 | 95–140 | 46 |

احتُفظ بنص الأسئلة والخيارات وبعلامات الإجابات الصحيحة من الملفين. ترقّم المنصة الأسئلة من البداية داخل كل اختبار. معرّفات الأسئلة في البيانات تحتفظ بأرقامها الأصلية لتسهيل المراجعة.

## التشغيل والفحص

موقع ثابت يستخدم ملفات JSON في `data/` ويعمل عبر GitHub Pages. لتشغيله محليًا، نفّذ `python -m http.server` من مجلد المستودع، ثم افتح العنوان المحلي الذي يطبعه الخادم. لفحص البيانات شغّل `node tools/validate-data.js data`، ولاختبار المحرك شغّل `node tools/test-core.js`. اختبار الواجهة متاح من مجلد `tools` بالأمر `npm run test:ui`.
